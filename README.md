## PCAssembly

One Step at a Time: Interactive PC Assembly Guidance

## Project Overview

PCAssembly is an interactive web-based application designed to guide users through computer hardware assembly and maintenance tasks.

The project explores how augmented-reality-style visual guidance can improve task completion compared to traditional instruction manuals.

Through an on-screen simulation, users will interact with computer components while receiving step-by-step instructions, visual highlights, and safety warnings.

The aim is to create an intuitive learning environment that reduces errors, improves task efficiency, and minimises cognitive workload.

## Research Question

Does augmented reality guidance that highlights the correct component and displays one instruction at a time help users complete computer maintenance tasks faster and with fewer errors than traditional manuals, without compromising safety?

## Planned Features

The application aims to provide the following features:

- Interactive PC Components: Users can interact with different computer components through a      simulated interface.
- Step-by-Step Guidance: Instructions are presented individually to help users focus on their current task.
- Visual Highlights: Important components are highlighted to guide users' attention.
- Safety Warnings: Users receive alerts when potentially unsafe actions are attempted.
- Pause and Resume: Users can pause instructions and continue when ready.
- Error Detection: The application identifies incorrect interactions and provides appropriate feedback.
- Performance Tracking: Task completion times, errors, and pauses are recorded for evaluation.

## Research and Evaluation

The project will investigate the effectiveness of interactive visual guidance compared to traditional instruction manuals.

## Evaluation Metrics

The study aims to measure:

- Task completion time.
- Number of errors.
- Responses to safety warnings.
- Perceived workload.

The results will be analysed to evaluate the effectiveness of the interactive guidance system.
